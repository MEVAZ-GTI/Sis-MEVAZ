# Sis-MEVAZ
A Metodologia para o Cálculo de Vazões (MEVAZ) é a metodologia oficial para a estimativa das séries de vazões afluentes aos reservatórios no Ceará e de sua oferta hídrica de longo prazo.  Este repositório contém o pacote R `SisMEVAZ` e sua interface web em R/Shiny. Os dados operacionais devem ser baixados conforme o manual.
